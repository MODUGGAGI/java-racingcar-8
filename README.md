## 구현할 기능 목록

---

### 입력

- [X]  경주할 자동차 이름 입력 (쉼표로 구분)
- [X]  시도할 횟수 (양의 정수)

### 출력

- [X]  매 회차 마다 실행결과 출력
- [X]  최종 우승자 출력

### 기능

- [X]  자동차 생성 (이름 통해서)
- [X]  0~9 사이의 난수를 통해 전진 여부 결정  
⇒ 각 자동차별로 실행  
- [X]  마지막 회차까지 진행 완료 후 가장 많이 전진한 자동차 결정

### 예외 처리

- [X]  시도할 횟수가 정수가 아니거나 음수가 입력되는 경우
- [X]  자동차 이름이 5자 이상인 경우
- [X]  자동차 이름이 중복된 경우
